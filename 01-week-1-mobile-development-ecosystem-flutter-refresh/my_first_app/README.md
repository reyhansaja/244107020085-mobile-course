## Refleksi

- Kapan native lebih tepat dipilih daripada cross-platform?
  Native lebih tepat ketika aplikasi membutuhkan akses maksimal terhadap kemampuan platform dan performa yang sangat spesifik.

Contohnya:

    - Aplikasi dengan kebutuhan performa tinggi, seperti game berat atau aplikasi dengan rendering kompleks.
    - Aplikasi yang banyak menggunakan fitur hardware/platform, misalnya Bluetooth khusus, NFC, background service, sensor, kamera tingkat lanjut, atau integrasi sistem operasi yang kompleks.
    - Aplikasi yang harus mengikuti desain dan behavior platform secara sangat detail.
    - Ketika fitur baru dari Android atau iOS harus bisa digunakan segera tanpa menunggu dukungan framework cross-platform.

- Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
  - UI adalah representasi dari state. Saat state berubah, framework mengevaluasi ulang widget/component tree dan memperbarui bagian UI yang relevan.

- Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
  - Commit kecil: Memudahkan code review, debugging, rollback, dan memahami riwayat perubahan. Pesan commit yang jelas juga menunjukkan cara kerja profesional dalam portfolio.
